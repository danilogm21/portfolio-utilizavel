< / > Introduction to Cybersecurity

Compreendi como proteger minha presença digital e dominei os conceitos básicos da segurança da informação. Aprendi a identificar as principais ameaças virtuais, aplicar técnicas de defesa cibernética e conheci as boas práticas essenciais para manter redes e dados seguros.

< / > Introduction to AI

Neste curso, aprendi os conceitos fundamentais da Inteligência Artificial e compreendi como ela está transformando o mercado e a sociedade. Explorei os princípios de Machine Learning, o funcionamento de redes neurais e a importância do uso ético e responsável das ferramentas de IA no cotidiano.

< / > HTML Essentials

Dominei a linguagem base de toda a Web e aprendi a construir a estrutura de páginas virtuais do zero. Compreendi o uso de tags para organizar textos e links, inserir mídias e criar formulários funcionais com uma estrutura semântica correta.

< / > CSS Essentials

Aprendi a estilizar páginas da web e a criar interfaces visuais modernas e responsivas. Dominei a aplicação de cores, tipografia e seletores CSS, além de estruturar layouts complexos usando Flexbox e CSS Grid para adaptar sites a telas de computadores e celulares.

< / > Computer Hardware Basics

Explorei o funcionamento interno dos computadores e aprendi o papel de cada componente físico da máquina. Identifiquei as funções do processador, memória RAM, placa-mãe e armazenamento, além de compreender conceitos básicos de montagem, manutenção e diagnóstico de problemas.
